11507 - Bender B. Rodríguez Problem

題目要求

題目中的金屬線（metal wire）可以想像成一條可彎折的鐵絲。它的長度為 L，固定端在原點，自由端一開始位於 (L, 0, 0)，因此整條線沿 +x 方向。Bender 從自由端往固定端依序處理 L - 1 個彎折點：No 表示不彎，其他指令表示在該點轉彎 90 度。題目要輸出全部彎折完成後，末段線的方向。

解法概念：追蹤末段方向

只要追蹤自由端末段的方向，不必計算自由端最後的位置。用方向向量 d = (x, y, z) 表示目前末段的方向，初始朝 +x，所以 d = (1, 0, 0)。No 不改變方向；其他指令則根據目前方向更新向量。

以 L = 3、指令依序為 +y、-y 為例，圖中逐步追蹤末段方向；處理完兩個指令後，方向仍是 +x。

題目只要求末段方向，因此圖只呈現計算時追蹤的向量狀態，不畫整條線的位置座標。箭頭表示依輸入順序處理指令，也就是從自由端往固定端。

圖中示範了方向狀態如何依序更新；接下來把四種彎折指令整理成一般的向量規則。

彎折指令的向量規則

假設彎折前的方向向量是 d = (x, y, z)，彎折後是 d' = (x', y', z')。各指令依下列規則更新分量；右側的 x、y、z 都是彎折前的值：

指令 彎折後的向量 d'
+y (-y, x, z)
-y (y, -x, z)
+z (-z, y, x)
-z (z, y, -x)

以 +y 為例，彎折前朝 +x 的分量會轉向 +y，朝 +y 的分量會轉向 -x，而 z 分量不變。因此彎折前的 d = (x, y, z) 會變成 d' = (-y, x, z)，也就是 x' = -y、y' = x、z' = z。公式右側都是彎折前的分量。這些更新在數學上等價於 90 度旋轉，但程式不必建立旋轉矩陣，也不需要浮點數。

因為初始方向是座標軸方向，而每次彎折只會交換分量並改變正負號，方向始終是以下六種之一：+x、-x、+y、-y、+z、-z。換句話說，三個分量中只有一個是 1 或 -1，另外兩個是 0。因此可以把這六個方向編號，預先整理每種方向遇到各指令後會變成什麼方向。

下表就是把上面的向量規則列舉成六種方向的轉換表。列是彎折前的方向，欄是本次指令，交叉處是彎折後的方向。例如目前朝 +z 時，向量是 (0, 0, 1)；套用 +y 規則仍是 (0, 0, 1)，所以方向不變。

目前方向 +y -y +z -z
+x +y -y +z -z
-x -y +y -z +z
+y -x +x +y +y
-y +x -x -y -y
+z +z +z -x +x
-z -z -z +x -x

程式如何套用轉移表

程式不必真的存三個分量，而是以 0 到 5 分別代表 +x、-x、+y、-y、+z、-z。nextDirection 將向量規則整理成查表：列索引是目前方向，欄索引是 +y、-y、+z、-z。每讀到一個非 No 指令，就查表更新方向；全部處理完後，從名稱表輸出結果。

每筆測資讀取 L - 1 個指令，時間複雜度為 O(L)，除固定大小的轉移表外只使用常數額外空間。

驗證

  • UVa 官方範例通過。
  • uDebug 第二組公開測資（24 組彎折組合）通過；第一組 100 筆的轉移結果也與 Accepted Output 相符。
  • 本機以 C++11 編譯後，與獨立的整數向量旋轉參考程式比對 19,531 組案例：涵蓋 6 次彎折以內的所有指令序列，另含 L = 100000 的長案例，結果一致。
