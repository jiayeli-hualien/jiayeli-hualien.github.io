10004 - Bicoloring

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 10004 - Bicoloring 題目

解法

題目給定連通的無向圖，要判斷能否把每個節點塗成兩種顏色之一，並確保每條邊的兩端顏色不同。以 0 表示未上色，1 和 -1 表示兩種顏色。

從節點 0 開始做深度優先搜尋（DFS），並先將它塗成 1。對目前節點的每個鄰點，預期顏色必須與目前節點相反：若鄰點尚未上色，就塗上相反顏色並繼續搜尋；若已上色但顏色不符，圖就無法二分著色。

題目保證圖連通，因此從節點 0 出發即可走訪所有節點。使用鄰接串列時，DFS 的時間複雜度為 O(V+E)。
