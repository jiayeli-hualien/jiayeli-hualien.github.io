10315 - Poker Hands//德州撲克牌比大小

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

牌型比較方式參考題目敘述與維基百科的德州撲克規則。

比較技巧參考調和的靈感。我用迴圈逐項比較，寫法較直接，但邏輯稍微複雜。

牌型比較不需要考慮花色，因此實作比想像中簡單。

建議先弄清楚規則再動手，尤其要注意花色不參與比較，以及順子的定義。

解法:

1.先統計每種點數出現的次數、每種花色出現的次數。

(單純看牌寫起來很煩，而且迴圈比較複雜)

2.依照先比出現次數在比點數大小排序五張牌

3.根據4,5,6取得牌型。

4.連續5種點數出現一次為順子。

5.根據每種花色出現的次數偵測同花，又順又同花則是同花順。

6.根據單張牌出現的次數，偵測對子、三條、四條、葫蘆、雜牌。

7.取得牌型後，先比牌型，若牌型相同則比較單張牌的點數

因為已將每張牌排序，除了順子類要特別處理以外，對子、三條、四條、葫蘆、雜牌可以用字典順序的方式比較大小。

UVa 10033 - Interpreter

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 10033 - Interpreter 題目

解法

題目要求模擬一台有 10 個暫存器和 1000 個 RAM 位址的電腦。指令和數值都是三位數，運算結果取模 1000。程式計數器從位址 0 開始，每次執行一條指令，直到執行 100 停止；執行次數包含停止指令。

依指令首位數處理操作：2 至 4 對暫存器設定常數、加上常數或乘上常數；5 至 7 對暫存器之間複製、相加或相乘；8 從 RAM 載入資料；9 將暫存器資料存入 RAM。0 是條件跳躍，只有指定的暫存器非零時才跳到另一個暫存器指定的位址；否則程式計數器加一。

逐條執行指令並更新暫存器、RAM 和程式計數器，即可完成模擬。題目保證每個程式都會停止。

UVa 10267 - Graphical Editor

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 10267 - Graphical Editor 題目

原文列出的參考資料：

  • C++ Blog：Graphical Editor
  • Chchwy Blog
  • UVa 討論區

解法

畫布大小為 M 欄、N 列，初始像素都是白色 O；座標從左上角開始，x 是欄、y 是列。L、V、H 和 K 分別用來塗單一像素、畫垂直線、畫水平線及填滿矩形。S 輸出檔名和目前畫布，X 結束操作。

F x y C 以指定像素為起點，將所有同色且透過上下左右相鄰連通的像素改成顏色 C。程式用佇列做廣度優先搜尋；像素改色時就視為已拜訪，避免重複入列。如果起點已是目標顏色，直接結束填色即可。

V 和 H 的端點可能以任一順序輸入，程式先整理成遞增順序再逐格畫線。K 的座標由題目定義為左上角和右下角，因此直接畫出包含兩端點的矩形。

10189 Minesweeper

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 10189 - Minesweeper 題目

解法

先把安全格的計數設為 0。每遇到一顆地雷，就檢查周圍八格，將相鄰的安全格計數加一。所有地雷處理完後，輸出每個欄位的結果。每格只會被檢查固定八個方向，因此時間複雜度為 O(NM)。

程式在地圖四周保留一圈 \0 邊界；更新鄰格時略過地雷和 \0，因此不會把邊界外的位置算進去。

每個欄位先輸出 Field #x:，接著輸出 N 列結果；欄位之間要空一行，第一個欄位前不加空行。

103 - Stacking Boxes

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

參考資料：解題文章；UVa 題目敘述

解法

題目允許任意重排箱子的維度。先將每個箱子的維度由小到大排序；排序後，箱子 A 能套入箱子 B，當且僅當 A 的每一維都嚴格小於 B 的對應維度。

把「能套入」視為由小箱子指向大箱子的關係，這些關係不會形成環。依此關係做拓樸排序，再用動態規劃計算以每個箱子為終點的最長套疊序列，最後透過前驅位置還原一條最長序列。

若有多條同樣長的最長序列，輸出任意一條都符合題意。

101 The Blocks Problem

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 101 - The Blocks Problem 題目

解法

每個位置代表一疊積木。程式用鏈結串列記錄每疊積木的順序，並用一個虛擬節點作為每疊的表頭。處理指令時，先找到積木 a 和 b 所在的位置；若兩者在同一疊，依題目規則忽略這個指令。

四種指令的差別，在於要不要先把積木歸位，以及要移動單塊或整疊：

指令 執行方式
move a onto b 將 a 上方的積木和 b 上方的積木各自歸位，再把 a 放到 b 上。
move a over b 將 a 上方的積木歸位，再把 a 放到 b 所在那疊的頂端。
pile a onto b 將 b 上方的積木歸位，再把從 a 開始的整疊移到 b 上。
pile a over b 把從 a 開始的整疊移到 b 所在那疊的頂端。

移動整疊時，a 上方積木的相對順序保持不變。指令都處理完後，依序輸出每個初始位置上的積木。

100 The 3n + 1 problem

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 100 - The 3n + 1 Problem 題目

解法

對每個輸入範圍，逐一計算其中整數的 cycle length，並找出最大值。cycle length 是從起始數字開始，依規則反覆轉換直到得到 1 的數字個數，起點和最後的 1 都要計入。輸出時保留輸入的 i、j 順序，即使計算範圍時先交換端點。

偶數除以 2，奇數乘以 3 再加 1。程式用查表快取已算出的 cycle length；若序列走到快取中已有結果的數字，就將已走過的步數加上該快取值。未命中的數字則繼續依規則計算。

這份程式以 long long 儲存序列中的暫存值。UVa 題目對正式輸入範圍另保證運算不會超出 32 位元整數；因此原文以超過 32 位元的數字說明「必須使用 long long」並不適用於這個 UVa 題目範圍。

102 Ecological Bin Packing

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

UVa 102 - Ecological Bin Packing 題目

解法

三個箱子分別放一種顏色的瓶子，因此只需考慮 B、G、C 對應三個箱子的六種排列。對每種排列，計算已經放對箱子的瓶子數；總瓶數減去放對的數量，就是需要搬動的瓶數。

選擇搬動數最少的排列。若有多種排列的搬動數相同，題目要求輸出字典序最小的字串，因此比較所有候選排列時也要處理平手情況。
