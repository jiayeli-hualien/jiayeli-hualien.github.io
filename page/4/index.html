568 - Just the Facts

UVa 568 要求輸入多個 n（0 ≤ n ≤ 10000），輸出 n! 最後一個非零位數。每行先以寬度 5 靠右印出 n，接著輸出 -> 和答案。0! = 1，所以輸入 0 時答案是 1。題目敘述

逐步計算並移除尾端零

不需要保存完整的階乘。從 0! = 1 開始，每一步乘上下一個整數，並立刻移除結果末尾所有的零。末尾零來自因數 10，也就是一個因數 2 和一個因數 5 配成一組；移除它們不會改變最後非零位數。

程式只保留目前結果的最後 14 位。這個位數足以處理題目的範圍：每次乘上的 n 不超過 10000，其中最多含 2^13（8192）或 5^5（3125）。目前結果已移除尾端零，所以不會同時含有因數 2 和 5；乘上 n 後，每一步最多新增 13 個尾端零。保留 14 位，即使移除這些零，也至少還剩一位可供下一步計算。

最大乘積小於 10^14 × 10000 = 10^18，可用 64 位元整數保存。初始化 factorialTail[0] = 1，也能正確處理 0!。

10222 - Decode the Mad man

UVa 10222 給一段由鍵盤誤打的訊息。每個字母或標點代表標準鍵盤上向右兩格的按鍵，請將它往左還原；空格保留。輸入只有一段訊息，輸出解碼後的內容。題目敘述

按鍵盤列往左移兩格

把鍵盤分成數字列、上排字母列、中排字母列和下排字母列。對每個字元，找到它所在列的位置，再取同一列往左兩格的字元。每列分開查找，避免把列首字元錯誤地接到上一列末尾。

題目範例中的大寫 I 會解成小寫 y，所以處理前先把字母轉成小寫。空格不在鍵盤表中，查不到時原樣保留。

10783 - Odd Sum

UVa 10783 要求計算閉區間 [a, b] 中所有奇數的總和。輸入先給測資數 T，接著每筆提供 a、b（0 ≤ a ≤ b ≤ 100）；每筆輸出 Case i: sum。題目敘述

用前綴和計算區間總和

定義 oddPrefix[i] 為小於 i 的奇數總和。以 [3, 9] 為例，oddPrefix[10] 是 1 + 3 + 5 + 7 + 9 = 25，oddPrefix[3] 是 1，相減後得到區間內的總和 24。

所以 [a, b] 的答案是 oddPrefix[b + 1] - oddPrefix[a]。用 b + 1 納入右端點；這個寫法也能直接處理 a = 0，不必存取 a - 1。

前綴和只需從 0 到 100 建立一次。每格先複製前一格的總和，遇到奇數再加上它；每筆測資就能用一次相減在常數時間內回答。

UVa 驗證結果

10008 - What's Cryptanalysis

UVa 10008 給定一段文字，要求統計每個英文字母出現的次數。大小寫視為同一個字母，空格、標點和數字都忽略；輸出只列出至少出現一次的字母，依次數由多到少排列，次數相同時按字母順序排列。題目敘述

統計 26 個字母再排序

固定使用 26 個計數器記錄 A 到 Z 的出現次數。讀取每一整行，逐字檢查：大寫字母用 ch - 'A' 找到位置，小寫字母用 ch - 'a' 找到相同位置，其他字元不計數。

統計完成後，只把出現過的字母放入清單，再依「次數遞減、字母遞增」排序並輸出。若共有 L 個輸入字元，時間複雜度為 O(L + 26 log 26)；計數器和排序清單最多各存 26 個項目。

575 - Skew Binary

UVa 575 要把 skew binary 數字轉成十進位。從右邊數第 k 位的權重是 2^(k + 1) - 1，位數可以是 0、1，最右側的非零位也可能是 2。輸入每行一個數字，0 表示結束；每個數字的十進位值不超過 2^31 - 1。題目敘述

由右向左累加位值

各位的權重依序是 1, 3, 7, 15, ...，每一項都等於前一項乘 2 再加 1。因此從最右位開始，逐位乘上目前權重並加進答案，再更新權重即可。

例如 10120 的計算是 1 × 31 + 0 × 15 + 1 × 7 + 2 × 3 + 0 × 1 = 44。程式用 64 位元無號整數保存權重和答案，並以 0 作為輸入終止標記。

C++11 程式

每個輸入位數只處理一次，時間複雜度為 O(D)，其中 D 是位數；額外空間用來保存目前的輸入字串。

這份 C++11 程式提交至 UVa 後獲得 Accepted（submission 31355652，0.000 秒）；本機輸出與官方範例一致。

579 - ClockHands

UVa 579 給定時間 H:M，要輸出時針和分針之間較小的角度，四捨五入至小數點後三位。時間以 0:00 結束；H 為 1 到 12，M 為 00 到 59。題目敘述

先求兩根指針的位置

時針每小時轉 30°，每分鐘再前進 0.5°，所以時間 H:M 的時針角度是 30H + 0.5M。分針每分鐘轉 6°，角度是 6M。

兩角相減並取絕對值，得到一個 0° 到 360° 的角度差 d。兩根指針之間較小的角度是 min(d, 360° - d)。例如 8:10 時，時針在 245°，分針在 60°，角度差為 185°，因此答案是 175°。

UVa 驗證結果

文章程式與 archive 中的 Accepted 版本完全相同，因此沒有重新提交 UVa。程式以 C++11 編譯，官方範例輸出正確。
