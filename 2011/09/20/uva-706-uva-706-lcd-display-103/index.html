解法

1.把數字切成七個部位存數字的長相

2.把印出數字切成五個部位處理

3.印完一組記得換行

4.注意格式，此題要補滿空白再換行

小解說

1.'\0'是字元結束符號，所以不需要先用strlen統計長度

2. '0' 的ASCII是 48

3.會用temp預存只是因為同一件事情我不想做好幾遍

void show_dash(const int &s, const char input[],int type)
{
    for(int i=0; input[i]!=‘\0’; i++)
    {
        if(i>0)
            putchar(‘ ‘);
        putchar(‘ ‘);
        for(int j=0; j<s; j++)/width 1+s+1/
        {
            if(sample[input[i]-48][type])
                putchar(‘-‘);
            else
                putchar(‘ ‘);
        }
        putchar(‘ ‘);
    }
    putchar(‘\n’);
}
