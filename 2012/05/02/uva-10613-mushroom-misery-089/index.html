10613 - Mushroom Misery //真菌增生!?

初版驗證狀態：尚未完成目前程式與原始 Accepted 紀錄的比對；後續確認後會補上驗證資訊。

我是在演算法筆記上看到這題的。

 

題目的大意就是，給你N，有個N*N的範圍。接著長出了許多真菌，分別給你圓心與半徑，要計算出被覆蓋的方格數量。方格數量接近CPU 1秒能處理的計算量的極限。

 

 

 

然後從UVA官方討論區看到解法如下：

將圓切成矩形

 

　　顧名思義就是把圓形變矩形，我的作法是先將圓形變成一條一條的長方形，之後使用演算法筆記當中的「舉例：宴會中訪客數目的極大值（ Interval Partitioning Problem ）」，排序進出順序，並將「無矩形覆蓋方格變成有矩形覆蓋方格，再變回無矩形覆蓋方格」的發生點抓出來，透過相減得到覆蓋格數。如圖示，詳細運作過程可看演算法筆記。

 

 

那麼如何取出in跟out的地點呢?

 

設半徑為r，先找某個離圓心很近的水平線，向外延伸 r 格，之後利用畢氏定理與高斯符號求出左右延伸的範圍。

更細一步講，我將整個圓分成上區、下區、mid區去計算，另外還有許多差一格、超出邊界之類的實作細節就不贅述了。

 

總結：

  1. 將圓切成很多條長方形
  2. 一行一行處理in out的點，統計覆蓋格數

struct RECT
{
    int h;
    int in, out;//L bound, R bound
}squence[2000000];


bool cmp(RECT A, RECT B)
{
    return A.h<B.h;
}


void addRect(int h, int i, int o)
{
    squence[acc].h = h;
    squence[acc].in = i;
    squence[acc].out = o;
    acc++;
    return;
}


int computeIn(double X, double Y, double R,int i)//left bound
{
    return max(0,(int)floor(X-sqrt(RR-(Y-i)(Y-i))));
}


int computeOut(double X, double Y, double R,int i,int size)//right bound
{
    return min((int)ceil(X+sqrt(RR-(Y-i)(Y-i))),size);
}
