10167 - Birthday Cake

UVa 10167 要用直線把圓形蛋糕切成形狀相同的兩半。蛋糕上有 2N 顆櫻桃，切開後每一半都要有 N 顆，切割線上也不能有櫻桃。要讓兩半形狀相同，切割線必須通過圓心 (0, 0)。將切割線寫成 Ax + By = 0，就能根據每顆櫻桃的 Ax + By 正負判斷它位於哪一側，再搜尋符合條件的整數係數 A、B。

用內積判斷櫻桃在哪一側

一般直線可寫成 Ax + By = C。本題的切割線必須通過原點 (0, 0)，因此 C = 0，直線方程式是 Ax + By = 0。向量 (A, B) 是這條直線的法向量，也就是垂直於直線的向量。對每顆櫻桃的座標 (x, y)，計算它與 (A, B) 的內積 (A, B) · (x, y) = Ax + By。這個內積值大於 0 表示櫻桃在法向量所指的一側，小於 0 表示在另一側；等於 0 則表示櫻桃在線上，這組係數不能使用。

例如官方範例的 N = 2，四顆櫻桃的座標是 (-20, 20)、(-30, 20)、(-10, -50)、(10, -5)。取 (A, B) = (0, 1) 時，切割線是 y = 0，內積值就是各點的 y 座標。前兩顆位於直線上方，後兩顆位於下方，因此兩側各有兩顆櫻桃。

下圖把這個切割方式畫在圓形蛋糕上：綠色箭頭是法向量 (A, B) = (0, 1)，與水平切割線 y = 0 垂直。藍色點在直線上方，橘色點在下方；右側列出每顆櫻桃的座標和內積值，方便對照正負號與位置。

搜尋係數

題目保證每組輸入至少有一組解，且 A、B 都在 [-500, 500]；兩者不能同時為 0，否則方程式不代表一條直線。又因為 N ≤ 50，最多只有 100 顆櫻桃，所以可以枚舉係數，逐一檢查每顆櫻桃。(A, B) 與 (-A, -B) 表示同一條線，只會把正、負兩側對調；因此只搜尋 A ≥ 0 不會漏掉答案。當 A = 0 時，方程式變成 By = 0，只要 B 不為 0，就等同於 y = 0，因此只需檢查 (0, 1)。題目接受任一組符合條件的答案，找到第一組就可以輸出。

檢查一組係數時，如果發現櫻桃在線上，就停止檢查這組係數；如果任一側已經超過 N 顆，也可以提早停止，因為後續櫻桃無法讓數量平衡。找到兩側各有 N 顆櫻桃的係數後，就輸出答案。利用 (A, B) 與 (-A, -B) 的對稱性後，最多檢查約五十萬組係數；每組最多檢查 2N ≤ 100 顆櫻桃，最壞情況約要判斷五千萬次櫻桃位於切割線哪一側，因此直接搜尋就足以應付本題。時間複雜度為 O(500^2 N)，額外空間為 O(N)。

C++11 程式

驗證

整理版以 MSYS2 UCRT64 g++、-std=c++11 -Wall -Wextra -pedantic 編譯，通過官方範例及自建案例。uDebug 提供 256 組測資；由於本題允許多組答案，逐組依題目條件檢查係數範圍、切割線上沒有櫻桃，且兩側各有 N 顆。UVa 題目敘述 · uDebug 測資
