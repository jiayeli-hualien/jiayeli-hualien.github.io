10041 - Vito's Family

題目要求

第一行是測試筆數。每筆測資給定親戚人數和各家的門牌，請替 Vito 選一個住址，讓他到所有親戚家的距離總和最小，並輸出這個總和。兩個門牌的距離是兩者相減後的絕對值；多人也可能住在同一個門牌。

本題可以用兩種方式解：暴力法逐一嘗試親戚家的門牌；排序法則直接選中位數。 剛開始學迴圈，可以先看暴力法；已熟悉排序，就可以直接用中位數減少計算量。

關鍵性質：最佳住址可以選中位數

將門牌排序後，選中間的位置當住址，就能讓到所有親戚家的距離總和最小。這是中位數使絕對距離總和最小的性質，可參考 Wikipedia：Median 的最佳化性質。

直覺上，把最左邊與最右邊的親戚配成一對，只要住址在兩者之間，到這一對的距離總和就相同。由外向內配對後，各對區間共同包含的中間位置，就是最佳選擇。

人數是奇數時，選正中間的門牌；人數是偶數時，兩個中間門牌之間的任一位置都能得到最小值，不必特地取兩者的平均。例如親戚住在 2 和 4，選 2、3 或 4 的距離總和都是 2。

解法一：暴力枚舉候選住址

把每位親戚的門牌輪流當作候選住址，計算到所有親戚家的距離總和，再取最小值。外層迴圈選住址，內層迴圈累加距離。

為什麼只試親戚家的門牌就夠？奇數人時，中位數就是其中一家的門牌；偶數人時，兩個中間門牌都是最佳區間的端點。因此，候選之中一定有最佳住址，不需要把所有可能的門牌逐一試過。

若有 r 位親戚，共有 r 個候選，每個候選要計算 r 次距離，所以時間為 O(r²)。題目的 r < 500，距離計算最多為 499 × 499 = 249001 次，這個做法也足以通過。

解法二：排序後取中位數

先把門牌由小到大排序，取出中位數，再逐一計算各家到中位數的距離並加總。

索引從 0 開始，所以可直接取 streetNumbers[r / 2]：奇數人時是正中間的門牌；偶數人時是兩個中間門牌中較大的那一個，也在最佳區間內。

例如門牌為 6、2、4，排序後是 2、4、6，選 4，距離總和為 2 + 0 + 2 = 4。

排序需要 O(r log r)，最後累加距離需要 O(r)，總時間為 O(r log r)。兩份程式都用 vector 保存門牌，需要 O(r) 空間。

兩種做法怎麼選？

做法 主要步驟 時間複雜度
暴力法 每個候選住址都算一次總距離 O(r²)
排序法 排序取中位數，只算一次總距離 O(r log r)

暴力法不需要先學會排序，但要知道候選住址為什麼包含最佳解。理解中位數的性質後，排序法能直接找到最佳住址，也能應付更多親戚的情況。兩種做法都適用於本題。

題目中每個門牌小於 30000、親戚少於 500，距離總和小於 15000000，使用 32 位元 int 足以保存。
