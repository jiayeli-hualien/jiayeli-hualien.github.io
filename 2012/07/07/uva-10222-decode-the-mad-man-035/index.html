10222 - Decode the Mad man

UVa 10222 給一段由鍵盤誤打的訊息：原本想輸入某個字元，卻按到標準鍵盤上同一列右邊兩格的按鍵。因此，解碼時要把收到的字元往左還原兩格；空白鍵不需要還原。輸入是一段訊息，輸出解碼後的內容。題目敘述

看圖還原按鍵

收到的按鍵往左數兩格，就是原本要輸入的按鍵。 下圖以 I 為例：向左經過 U，找到 Y。藍色標出收到的按鍵，橘色標出還原後的位置；圖中鍵帽以大寫標示，程式輸出則使用小寫。

表中只列出左側有兩個按鍵、能依規則還原的字元。接著用一段訊息，看看如何逐字查表。

以官方範例的 k[r dyt I[o 為例，逐字還原後會得到 how are you：

收到的單字 逐字對照 解碼結果

按鍵盤列查找

有了上面的對照規則，程式就不必逐一列出所有配對，只要把鍵盤的四列分別存成字串。

rows 是由 string 組成的一維陣列，每個字串保存一列鍵盤。因為字串內又有多個字元，所以可以像二維陣列一樣，用 rows[i][j] 取得第 i 列的第 j 個字元，索引從 0 開始。例如 rows[1] 是上排字母列，rows[1][2] 就是字元 e。

for (const string& row : rows) 會依序取出每一列字串，並以 row 存取該列。decode 先將字母轉成小寫，再找到它所在列的位置 position；當 position >= 2 時，取出 row[position - 2]，就是解碼後的字元。

空白鍵不需要還原：空白字元不在這四列字串中，查不到時會原樣傳回。程式也會保留每列最左邊兩個按鍵及表外字元，避免查到字串範圍外；字母則已在查找前轉成小寫。最後，逐字解碼並依原順序輸出，即可得到還原後的訊息。
